# wake-slate

## Reasoning

1. The name is two nouns and no brief. A wake is the moment something starts, and also the trail a body leaves in water. A slate is a surface that takes a mark and can be wiped. The page is that object, not a product wrapped around a name.

2. The usual “beautiful” page — full-bleed gradient, centered type, a button — was skipped. It would look like every other dark landing page. What is here is one thing in a room: a writing slate, wood frame, hanging hole, dawn leaking in under it.

3. It will be served as static files. No framework, no build, no second page. `index.html` is the frame, the stone, and the chalk. A downloaded font was skipped; Palatino and Georgia already read as an inscription. Sound was skipped; a slate does not need a speaker. Saved drawings were skipped; the point is that it forgets.

4. The frame, the hole, the inner border, and the dawn under the slab are CSS. Grain is one SVG turbulence filter laid over the stone, not a per-frame noise loop. The words “wake” and “slate” are HTML so the type stays sharp, sitting under the chalk layer.

5. Marks live on a canvas. Pointer down lays chalk and sends a ring out from the touch. Fast strokes are interpolated so the line does not break. Each mark’s life ticks down until it is gone. Mica flecks drift and brighten where the hand is. A lamp, a CSS radial gradient, follows the pointer so the stone wakes locally instead of all at once.

6. The mark list is capped and the fade is linear. That is enough for a hand writing on one slate. A dust simulation would be the upgrade if strokes should cake and clump.

7. Ambient motion — fleck drift, the dawn’s breath, the opening fade — stops when the visitor asks for reduced motion. Marks still appear. They only leave more slowly.

8. Nothing on the page tells anyone how to start a server. The file is the site.
